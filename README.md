# 基金对比平台（Fund Comparison Platform）

一个以**基金经理为核心**的全市场基金对比平台：覆盖约 2.8 万只基金、4,400 余位基金经理，支持全局搜索、多基金对比、经理主页、净值 K 线与持仓分析。数据全部来自天天基金 / 东方财富公开接口，服务端抓取解析后缓存，每日刷新。

## 在线使用（打开即用，无需安装）

**https://mons7hub.github.io/fund-comparison-platform/**

托管在 GitHub Pages 上，任何人打开网址就能直接使用，不需要注册或登录。页面数据（全市场基金 / 经理索引、排行、详情快照）由维护者每晚更新到 `docs/` 目录；K 线等实时数据由页面直接向天天基金公开接口拉取。

## 自行部署（快速开始）

需要 [Bun](https://bun.sh)（1.3+）：

```bash
bun install     # 安装依赖
bun run build   # 构建前端到 client/dist
bun run start   # 启动服务，打开 http://localhost:3000
```

- 端口可用环境变量修改：`PORT=8080 bun run start`
- 数据库是本地 SQLite 文件 `data/app.db`，首次启动时自动按 `drizzle/` 里的迁移建表，不需要任何配置
- 第一次打开会现场拉取全市场基金 / 经理索引（约 3 MB）并缓存，首屏可能要等几十秒；之后走缓存，按过期时间自动刷新
- 本项目**不需要任何 API Key**：数据接口均为公开接口

## 功能

- **全局搜索**：按基金名 / 代码 / 类型、经理名 / 公司 / 风格标签搜索；搜到的基金可直接加入对比栏（上限 4 只）
- **经理排行榜与经理主页**：多周期排行；经理页含其在管基金，以及公开采访 / 观点与定期报告展望的收录位（只收录真实可溯源内容，附来源链接）
- **基金排行与分类**
- **多基金对比**：收益、回撤、波动、费率、持仓等维度横向对比
- **净值 K 线**：日 / 周 / 月 K 线，MA5 / 10 / 20，累计净值合成；支持拖动选点与边缘自动移窗
- **持仓分析**：前十大持仓与行业构成（纯债基金切换为债券持仓），标注报告期
- **指数对比**：与上证指数、沪深 300、纳斯达克 100、标普 500 对比及逐年跑赢分析
- **投资者画像（可选）**：风险承受能力、最大可接受回撤、投资期限与目标等设置会影响对比页的定制建议、各基金「匹配度」徽章与排序
- **基金新闻**：按主题组织的因子新闻池，每只基金按自身因子画像匹配相关新闻，并说明关联原因

## 技术栈与结构

- 前端：React 19 + TypeScript + Tailwind CSS 4 + Recharts，Bun 构建
- 后端：Bun + TypeScript，Drizzle ORM + SQLite（bun:sqlite）
- 接口形式：前端通过 `POST /actions` 以 `{ action, args }` 调用服务端动作，参数经 zod 校验

```
client/            前端（React 应用与构建脚本）
server/
  src/actions.ts   全部服务端动作：搜索、排行、详情、对比、K 线、新闻池等
  src/schema.ts    数据库表结构
  src/standalone.ts 独立服务器入口（HTTP 服务 + /actions 分发 + 静态托管）
drizzle/           数据库迁移 SQL（启动时自动按序应用）
packages/sdk/      本地兼容层，见下文
```

## 关于 packages/sdk（兼容层）

本项目最初是在 Muse 平台（Muse Spaces）里开发的，前后端代码依赖平台的 `@hatch/space-sdk`（`defineAction` / `createActionClient` 等），该 SDK 未公开发行。为了让项目能独立运行，仓库内置了一个最小兼容层 `packages/sdk`（包名 `@fund-platform/sdk`），实现了同一套接口表面：

- 服务端：`defineAction`、动作的 `Ctx`（`ctx.db()` 返回 Drizzle 实例）
- 客户端：`createActionClient`（把动作调用 POST 到 `./actions`)、`spaceQueryClient`、`SafeAreaTopScrim`
- 构建：`buildClient`（Bun.build + Tailwind 插件）

应用代码因此无需改动逻辑即可在普通环境运行。兼容层与 Muse 平台无隶属关系。

## 独立版与平台版的差异

- **数据收录类动作**：经理采访 / 观点、基金新闻在平台版由 AI 代理定时检索后写入数据库；独立版没有代理运行时，这类「派发检索任务」的动作会返回未派发，页面展示数据库里已有的收录内容（新装时为空），其余读功能（搜索、排行、详情、K 线、对比等）全部正常，数据实时来自公开接口。
- **缓存刷新**：平台版有每日定时任务刷新缓存；独立版按缓存过期时间在请求时自动刷新，效果一致，个别首次请求会稍慢。
